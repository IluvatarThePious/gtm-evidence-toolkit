# Provenance and limits

Prepared October 1, 2026.

| Public component | Existing foundation | Added for this release |
|---|---|---|
| Call to Commitment | A transcript-to-follow-up prompt and the sales-analysis workflow in a privately configured GPT | Vendor-neutral instructions, source IDs, commitment states, synthetic transcript, reference output and failure cases |
| Value Case Lab | ROI-briefing GPT instructions that distinguish facts, measured inputs, assumptions and outcomes | Explicit intake, independent deterministic calculator, fictional scenarios, calculation tests, validation rubric |
| Career Evidence Companion | Interactive résumé GPT concept and repeated résumé/application refinement | Public-evidence allowlist, ownership distinctions, fictional career record, gap handling and adversarial questions |

The original concepts and task direction came from Peter's work. AI assisted analysis, generalization, implementation and documentation. The release does not establish sole authorship of underlying general business methods, customer adoption, or independently verified business impact.

No source conversation, knowledge attachment or employer template is reproduced. Original GPT configurations remain separate. All named organizations and people in the examples are fictional placeholders. The calculator is newly implemented for this package, not recovered production code.
