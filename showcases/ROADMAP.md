# Execution and publication roadmap
## Delivered now
Five reusable workflow modules, five synthetic input/reference pairs, 25 model-evaluation fixtures, a shared assistant router, per-project build plans, a deterministic pilot-gate checker with tests, and the existing value calculator.

## Build order
1. Deal Evidence Copilot (8–12h): most direct demonstration of daily enterprise-sales judgment.
2. Value Case Lab (5–8h): existing deterministic core makes a usable form/results application a bounded next step.
3. Pilot-to-Expansion (6–10h): strongest leadership example; review gate policy with an operating stakeholder before extending it.
4. Customer Proof Sprint (3–5h): complete an observed source-to-story exercise and show rejected claims.
5. Buyer Value Framework (4–7h): validate portability across two offerings and industries.

Total next-application estimate: 26–42 focused hours, plus scheduling, source approvals, and any model/tool setup. These are scope estimates, not a calendar commitment. Each module's BUILD_PLAN.md gives dependencies and acceptance criteria.

## Release gates
- Workflow-kit release: truthful README, accessible examples, tested deterministic code, no private source files, clear prototype limitations.
- Assisted-app release: runnable end-to-end task, editable review state, meaningful failure-case evaluation, raw evaluation records, and an observed unfamiliar-user exercise.
- Impact claim: measured baseline/comparison, defined sample/period, authorized evidence, and honest limitations. Publishing the kit does not satisfy this gate.

## Portfolio presentation
Feature the five-work-sample landing page in the profile and keep the two existing collections as the repository homes. Avoid splitting out five nearly empty repositories. If a tool develops its own runtime and release cycle, split it then and preserve its history and attribution.

Lead each interview with one decision: tentative versus agreed; capacity versus cash; successful pilot versus deployment readiness; persuasive versus supportable claim; feature versus buyer outcome. Record a 60–90 second walkthrough of that decision after an observed run. Do not claim improved hiring outcomes until measured.
