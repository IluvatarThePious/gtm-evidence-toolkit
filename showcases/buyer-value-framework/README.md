# Buyer Value Framework
**Translate an offering into buyer outcomes, neutral requirements, proof, and discovery questions.**

Audience: VPs of Sales, Sales Directors, CEOs, enablement leaders, and enterprise sellers.

## Try it in five minutes
1. Read [the fictional input](example-input.md).
2. Paste [the reusable instructions](instructions.md) and that input into your chosen assistant.
3. Compare its result with [the authored reference](reference-output.md).
4. Check the [failure cases](evaluation.json). These expectations are not recorded model results.

## Why this belongs in the portfolio
Buyer-centered messaging, causal reasoning, fair differentiation, and sales enablement that another seller can use.

The key judgment: **A feature is not a buyer value driver; a product page is not evidence that a named prospect has the pain or achieved a result.**

## From one-off work to reusable workflow
Generalizes the detailed buyer-value request in Draft Metaview value framework and related value-prompter work. The new module is independently written and excludes proprietary templates and employer collateral.

Existing foundation: A rich company-specific research and drafting workflow exists in prior queries. This portable module and synthetic reference case are new.

Reusable pipeline: Anchor the buyer workflow → identify one to three buyer-owned outcomes → connect before/after conditions and consequences → define vendor-neutral capabilities → map supported mechanisms → test differentiation → identify proof and discovery gaps.

Required inputs: Required: seller, offering, intended buyer segment, workflow, decision audience, and approved evidence pack. Optional: public primary product evidence, authorized customer research, alternative approaches, proof, metric baselines. If customer evidence is absent, explicitly deliver a hypothesis-led framework.

## What is delivered
Independent reusable instructions, a fictional source pack, an authored reference answer, five evaluation fixtures, and a [concrete build plan](BUILD_PLAN.md). No original customer records, GPT attachments, or employer templates are included.
