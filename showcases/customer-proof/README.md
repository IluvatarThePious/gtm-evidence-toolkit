# Customer Proof Sprint
**Turn authorized evidence into a useful customer story without inflating the result.**

Audience: Sales leaders, customer marketing, customer success, CEOs, and enterprise sellers.

## Try it in five minutes
1. Read [the fictional input](example-input.md).
2. Paste [the reusable instructions](instructions.md) and that input into your chosen assistant.
3. Compare its result with [the authored reference](reference-output.md).
4. Check the [failure cases](evaluation.json). These expectations are not recorded model results.

## Why this belongs in the portfolio
Customer advocacy, commercial storytelling, measurement literacy, and editorial judgment about claims that should be rejected.

The key judgment: **An observed reduction in draft preparation does not establish shorter end-to-end turnaround, payroll savings, causality, or customer endorsement.**

## From one-off work to reusable workflow
Builds on the existing fictional quote-preparation story and published Customer Proof Sprint package in the companion portfolio.

Existing foundation: A full fictional story, source ledger, slide outline, email drafts, reusable prompt, and arithmetic verification already exist. This release adds a reusable assistant module and concise review fixture.

Reusable pipeline: Inventory sources and permissions → compute comparable measures → classify claims → reject unsupported extensions → draft a bounded story → create proof-slide outline → audit each sentence against the ledger.

Required inputs: Required: source pack; audience; permission/approval status; outcome metric with denominator and period or a clearly qualitative result. Optional: customer quotes with speaker/locator, process description, limitations, implementation context, requested channels. If permission is missing, create an internal anonymized draft and a release gap list.

## What is delivered
Independent reusable instructions, a fictional source pack, an authored reference answer, five evaluation fixtures, and a [concrete build plan](BUILD_PLAN.md). No original customer records, GPT attachments, or employer templates are included.
