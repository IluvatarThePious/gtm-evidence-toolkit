# Call to Commitment

Turn one sales conversation into an evidence ledger, an action table and a short follow-up email. The key distinction: an attractive next step is not necessarily a buyer commitment.

1. Paste [prompt.md](prompt.md) into an assistant.
2. Add [example-input.md](example-input.md), or a record you are authorized to use.
3. Compare with [reference-output.md](reference-output.md).
4. Review the ledger and proposed actions before using the email.

This is a prompt workflow. It does not transcribe audio, validate a calendar, send email or integrate with CRM. The reference output is a fictional authored example.

## Before a public app

Build a simple flow: paste transcript → inspect source-linked facts → correct commitment states → export email and action table. Start with one call and one seller. Keep sending and CRM changes outside the first release.

Pass every case in [evaluation.md](evaluation.md), then test with three unfamiliar users. The product should clearly identify proposed versus agreed dates without the user needing to read its instructions.
